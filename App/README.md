# App Nerd-Wow (opcional)

O App Nerd-Wow é um complemento **opcional** do addon NerdWow para Windows. O addon funciona sozinho; o app serve para quem quer levar a história do personagem para fora do jogo.

## Download

O app é distribuído como **portátil** (não precisa instalar) na página de [Releases](https://github.com/ThiagoGregson/nerdwow_worldofwarcraft_addonLore/releases) deste repositório. Baixe o `.zip` da versão mais recente e extraia em qualquer pasta.

> O app ainda está em desenvolvimento. Esta página será atualizada quando a primeira versão for publicada.

## Por que o app não fica nesta pasta

Para manter o repositório leve, os arquivos do app não são guardados aqui. Cada versão fica disponível nas Releases.
